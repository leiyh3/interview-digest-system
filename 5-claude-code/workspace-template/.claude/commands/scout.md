argument-hint: [可选：天数或只看某一类，如“播客访谈”]
---

按 CLAUDE.md 的“每日素材采集”规则做今天的选题。附加要求：$ARGUMENTS

1. **收件箱。** 看 `scout/inbox/` 里今天的文件；没有就先运行 `.venv/Scripts/python.exe tools/scout.py fetch`。收件箱里“需要用网页工具查看的源”，用网页工具打开，只看最近 3 天发布的内容。
2. **初筛（只看标题和简介）。** 按三条标准粗看，留下最多 8 条候选：
   - 说话的人对普通观众是否有知名度
   - 有没有可能出现一句反直觉的话
   - 有没有可能提炼出一个具体数字或对比
   视频少于 15 分钟、纯产品广告、重复话题（`scout/pool.md` 里最近 14 天已经有的）直接跳过。
3. **细看。** YouTube 候选运行 `.venv/Scripts/python.exe tools/scout.py captions <链接>` 拿字幕文本，在字幕里找那句反直觉的话和那个数字，记下时间码。文章候选用网页工具读全文。
4. **打分。** 每条按三项各打 1 到 5 分：知名度、反直觉、数字或对比。反直觉和数字两项必须写出原话（英文原文加中文意思）和时间码；只凭标题简介判断的，写“未核实”，这两项最多给 2 分。
5. **写选题。** 写 `scout/pool/<今天日期>.md`：总分最高的 3 到 5 条，每条包括：
   - 来源、链接、发布日期、时长、素材形式（有视频画面 / 只有音频 / 文章，文章只能做图卡加讲解）
   - 三项分数和依据（原话、时间码）
   - 3 个标题草案：反转型、数字冲突型、悬念型，数字必须出自原话
   - 一句话：为什么值得做，以及最大的风险（人物陌生、内容太专业、版权或授权不明）
   然后在 `scout/pool.md` 末尾为每条加一行：日期、标题草案、总分、链接、状态（待选）。
6. **停下来等我。** 用 3 到 5 行列出今天的推荐和你最推荐的一条。我选中后，确认我有权剪辑这条素材，再用 `tools/new_episode.py <短名> --url <链接>` 建一期，然后按 /digest 的流程继续。没选中的，在 pool.md 里状态改成“跳过”。
