# 在本地 Claude Code 里跑访谈精读（Windows）

前提：Claude Code 已经装好并登录。一次性准备大约 20 分钟，大部分时间花在下载 whisper 上。之后每条视频按第三节的指令走。

下面的命令都在 **VS Code 的终端**（PowerShell）里运行：用 VS Code 打开工作区文件夹，按 ``Ctrl + ` `` 打开终端。第一节的准备脚本还没有工作区，可以在任意 PowerShell 窗口里运行。

## 一、一次性准备

**1. 运行准备脚本。** 解压 `interview-digest-system` 包，在 PowerShell 里：

```
cd <解压位置>\interview-digest-system\5-claude-code
powershell -ExecutionPolicy Bypass -File setup_windows.ps1
```

工作区默认建在 `%USERPROFILE%\digest-workspace`。想放别处就在最后加路径，比如 `... -File setup_windows.ps1 D:\digest-workspace`。路径里最好不要有中文和空格。

脚本会做四件事：
1. 用 winget 装 ffmpeg 和 Python（已经装了就跳过）
2. 建工作区，放好 skill、两个评审子智能体和 `/digest` 指令
3. 在工作区里建 Python 虚拟环境，装 Pillow、numpy、whisper、yt-dlp
4. 用一条合成视频试跑剪辑和审片

如果提示“刚装了 ffmpeg 或 Python”，关掉窗口，开一个新的 PowerShell，再运行一次同样的命令。

看到“环境可以用”就成功了。打开 `data\smoke_preview.mp4`，看一眼中文图卡和字幕是否正常。字体默认用系统自带的微软雅黑，不用另装。

**2. 填账号信息。** 用记事本打开工作区里的 `CLAUDE.md`，填“账号信息”那几行。

**3. （可选）放数据表。** 抖音、视频号后台导出的视频列表，另存为 `data\douyin.csv` 和 `data\channels.csv`。Excel 另存时选“CSV UTF-8”，否则中文会乱码。第一次做的时候，在 Claude Code 里说：

```
分析 data/ 里的抖音和视频号数据表，按 skill 的 data_analysis.md 写 data/data_insights.md。
然后拿我已经发过的 3 到 5 条视频做一次评分校准，结论写进同一个文件。
```

## 二、工作区长什么样

```
digest-workspace\
├── CLAUDE.md                  工作区规则（账号信息、停顿点、硬规则）
├── .claude\
│   ├── skills\interview-digest-video\   skill 和全部脚本
│   ├── agents\                两个评审子智能体：digest-analyst、digest-audience
│   ├── commands\              /digest（做视频）和 /scout（挑选题）两个指令
│   └── settings.json          允许 ffmpeg 和工作区 Python 免确认运行
├── .venv\                     Python 虚拟环境（whisper 在这里）
├── tools\                     check_env.py、new_episode.py、scout.py、cover-studio.html
├── scout\                     每日素材：sources.json（素材源）、inbox\（每天新内容）、pool\ 和 pool.md（选题池）
├── data\                      数据表和 data_insights.md
└── episodes\<日期>-<短名>\     每条视频一个目录
    ├── notes.md               你的备注：来源、授权、谁坐哪边、你想讲的角度
    ├── source\                源视频和转写
    ├── vo\                    你的口播录音
    └── reviews\               评分和改动记录
```

## 三、每条视频的流程

### 第 1 步：建一期、放素材

```
cd $HOME\digest-workspace
.\.venv\Scripts\python.exe tools\new_episode.py andreessen --video $HOME\Downloads\interview.mp4
```

会建出 `episodes\<日期>-andreessen\`，视频复制成 `source\interview.mp4`。然后转写：

```
cd episodes\<日期>-andreessen\source
..\..\..\.venv\Scripts\whisper.exe interview.mp4 --model small --output_format json
cd $HOME\digest-workspace
```

- 先用 small 模型。英文访谈不要加 `--language zh`。没有独立显卡的电脑转写一小时的访谈会很久，可以先截 15 分钟试流程。
- 已经有字幕文件（SRT）或节目官方逐字稿，直接放进 `source\`，跳过 whisper。
- 填好 `notes.md`，尤其是授权说明和“画面里谁坐哪边”。

转写也可以交给 Claude Code 跑：第 2 步里说“先帮我用 whisper small 转写”就行。

### 第 2 步：在 VS Code 里启动 Claude，出精剪主线

你在 VS Code 终端里运行的 `claude` 命令就是 Claude Code，下面说的“在 Claude Code 里输入”，指的都是在这个终端里输入。

1. **用 VS Code 打开工作区文件夹。** 菜单“文件 → 打开文件夹”，选 `digest-workspace`（不是某一期的子文件夹，也不是上一级）。左侧资源管理器最上层应该能看到 `CLAUDE.md`、`.claude`、`episodes`。
2. **打开终端。** 按 ``Ctrl + ` ``，终端的当前目录会自动是工作区。不放心就先输入 `pwd` 看一眼，结尾应该是 `digest-workspace`。
3. **启动 Claude。** 在终端里输入 `claude` 回车。Claude 只会读取“启动时所在文件夹”里的 `CLAUDE.md`、skill、评审子智能体和 `/digest` 指令，所以一定要在工作区目录下启动。
4. **输入指令。** 在 Claude 的输入框里输入：

```
/digest episodes/2026-11-14-andreessen
```

把 `2026-11-14-andreessen` 换成这一期真实的文件夹名。不确定叫什么，看左侧 `episodes` 下面的文件夹；或者看第 1 步 `new_episode.py` 最后打印的那行命令，直接复制过来。

输入 `/` 时会弹出可用指令列表，能看到 `digest` 就说明工作区加载对了。看不到的话，多半是 Claude 不是在工作区目录下启动的：输入 `/exit` 退出，`cd` 到工作区，再运行 `claude`。也可以不用指令，直接粘贴这段：

```
用 skill interview-digest-video，按 CLAUDE.md 的规则处理 episodes/2026-11-14-andreessen：
检查素材，把转写合并成整句，通读并抽帧确认谁在说话，写 storyline.md，然后停下来等我。
```

Claude 写好 `storyline.md` 后会停下。你在左侧资源管理器里点开 `episodes\<这一期>\storyline.md` 看，然后在终端里回复：

- `开始`：按这个主线做
- 或者直接提修改，比如：`标题用第 2 个；要点三删掉；开头换成 21:52 那句`

### 第 3 步：口播（Claude 会停下来问你）

Claude 列出每段讲解的口播稿后停下。两种选择：

- 先看效果：回复 `先用静音占位，出预览`
- 录好再出：用手机或电脑录好，存成 `vo\n1.m4a`、`vo\n2.m4a`（文件名和片段 id 对应），回复 `口播录好了，在 vo/ 里`

第一条建议先用静音占位，看完预览、改好稿子再录，免得重录。

### 第 4 步：预览、技术审片、评审（自动）

Claude 会自己做：写 plan.json，翻译用到的句子，出 540×960 预览，跑技术审片，派两个评审子智能体，判定、修改，再进入下一轮，最多 4 轮。

你可以随时打开 `build\preview.mp4` 看。过程中常用的话：

| 想做什么 | 说什么 |
|---|---|
| 看进度 | `现在第几轮了，两个评审各多少分，卡在哪几项` |
| 自己提意见 | `我看了预览：1:20 那段太长，图卡字太多，按我的意见改一轮` |
| 两个方案选一个 | `用方案 B` |
| 跳过评审 | `这条跳过评审，技术审片通过就出成片` |
| 省 Token | `这条只派观众剪辑一个评审` |

### 第 5 步：成片和交接

预览通过、口播录好后，Claude 出 1080×1920 成片，再做一次技术审片，然后写 `reviews\HANDOFF.md`。

如果你用静音占位走到了这一步，先录口播，再说：`口播录好了，出成片`。成片里还有“待配音”或缺翻译的，技术审片会判 fail，交接里会写“不能发布”。

### 第 6 步：封面和发布（你自己做）

1. 用浏览器打开 `tools\cover-studio.html`，抖音和视频号各出一张（尺寸以发布页提示为准）。
2. 对照 `HANDOFF.md` 的“发布前请人工确认”逐项过一遍：数字和人名、来源标注、AI 内容标注。
3. 建议先在抖音私密发布一条，在手机上看字幕和图卡有没有被平台界面挡住。

## 四、每日素材采集

分两段：**机器每天定时拉新内容**（不花 Token），**你想选题时让 Claude 挑**。

### 第一次设置

1. **检查素材源。** 在工作区终端里运行：

   ```
   .\.venv\Scripts\python.exe tools\scout.py check
   ```

   每个源会显示 OK 或 FAIL。素材源都在 `scout\sources.json`：播客访谈和大会演讲用 YouTube 频道，文章用 RSS，没有 RSS 的页面（Anthropic 新闻、Hugging Face 每日论文）由 Claude 用网页工具看。FAIL 的源，多半是 YouTube handle 写得不对：打开那个频道主页，把地址栏里 `@` 开头的部分填进去，再跑一次 check。想加源、停用某个源，也改这个文件。

   访问 YouTube 需要代理的话，先在当前终端设置，再运行（端口换成你自己代理的）：

   ```
   $env:HTTPS_PROXY = "http://127.0.0.1:7890"
   ```

2. **设定每天自动拉取。** 运行：

   ```
   powershell -ExecutionPolicy Bypass -File tools\register_daily_scout.ps1 -Time 08:00 -Proxy http://127.0.0.1:7890
   ```

   不用代理就去掉 `-Proxy ...`。之后每天 8 点会把过去几天的新内容写进 `scout\inbox\<日期>.md`；电脑当时关机的话，开机后补跑。同一条内容只会出现在一天的收件箱里。日志在 `scout\fetch.log`。

### 每天选题

在工作区里启动 `claude`，输入：

```
/scout
```

Claude 会按三条标准挑：说话的人有没有知名度、有没有一句反直觉的话、能不能提炼出具体数字或对比。

1. 先只看标题和简介，筛出最多 8 条候选。
2. YouTube 候选只下载字幕（不下载视频），在字幕里找到那句话和那个数字，记下时间码。
3. 三项各打 1 到 5 分；只凭简介判断的项标“未核实”，最多给 2 分。
4. 写进 `scout\pool\<日期>.md`：前 3 到 5 条，每条带原话、时间码、3 个标题草案和风险提示。同时在 `scout\pool.md` 记一行。
5. 停下来，等你选。

你回复选哪条（比如“做第 2 条，短名 garry-tan”），并确认有权剪辑后，Claude 会用 `new_episode.py --url` 下载视频、建好这一期，然后接着走 /digest 的流程。

也可以加条件，比如 `/scout 只看播客访谈` 或 `/scout 看过去 7 天`。

## 五、常见问题

**脚本报“无法加载，因为在此系统上禁止运行脚本”。** 用指南里的写法 `powershell -ExecutionPolicy Bypass -File ...` 运行，不要双击。

**winget 找不到。** 在 Microsoft Store 里更新“应用安装程序”（App Installer）。或者手动装：ffmpeg 从 gyan.dev 下载 full 版，解压后把 `bin` 目录加进系统 PATH；Python 从 python.org 下载 3.12，安装时勾选 “Add python.exe to PATH”。

**`subtitles` 滤镜报错，或中文显示成方块。** 运行 `.\.venv\Scripts\python.exe tools\check_env.py` 复查。ffmpeg 要带 libass（gyan.dev 的版本都带）；微软雅黑找不到时，在 CLAUDE.md 里加一句“渲染时加 --font-file C:/Windows/Fonts/simhei.ttf”。

**pip 装 whisper 失败。** 多半是网络问题，换个时间重跑准备脚本即可，已经装好的部分不会重装。

**Claude 每条命令都问要不要执行。** `.claude\settings.json` 已经放行 ffmpeg 和工作区 Python；其他命令第一次会问，选“以后都允许”即可。

**评审分数一直很高，但你觉得不好。** 分数只是参考。把你的意见直接说给 Claude，它会记成改动。连续几条都这样，说明评分标准要调，让 Claude 用你已发的视频重新校准。

**Token 用量大。** 评审最贵。校准过、连续两条稳定在 85 分以上之后，改成只派一个评审，或者只做技术审片。

**素材源拉取失败。** 先单独跑 `tools\scout.py check` 看是哪个源。全部失败多半是网络或代理；个别失败多半是 handle 或 RSS 地址变了。定时任务里的代理要在注册时用 `-Proxy` 传进去，终端里设置的 `$env:HTTPS_PROXY` 对定时任务不起作用。

**收件箱太多看不过来。** 在 `sources.json` 里把不常出好内容的源改成 `"enabled": false`，或者把 `lookback_days` 改小。

**更新 skill。** 拿到新版本的包后，重新运行一次准备脚本。skill、子智能体和工具会更新，你的 CLAUDE.md、数据和每期文件不会被覆盖。
