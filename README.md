# 访谈精读视频体系（v2）

把一条长访谈剪成 10 分钟以内的“精读”短视频，发抖音和视频号。成片由原片片段、你自己的讲解段和图卡组成，出片前走技术审片和两个评审，最后留下交接记录。灵感来自抖音账号“黄叔讲科技”的做法。

这个包可以整个带到另一个 Claude 工具里使用。

## 在哪个工具里怎么用

**Claude Code（推荐）**：看 `5-claude-code/本地运行指南.md`，运行 Windows 准备脚本建好工作区，之后每条视频输入 `/digest episodes/<某一期>`。这里能起子智能体，两个评审可以真正独立。

**支持上传 skill 的 Claude 应用**：上传 `1-skill/interview-digest-video.zip`。能不能跑脚本取决于那个环境，先用一条短视频试。

**只能聊天的工具**：把 `4-single-file/chat-prompt.md` 放进项目指令，需要细节时再放 ALL-IN-ONE。这时评审不独立，分数只作参考。

## 环境要求（脚本部分）

- Python 3，加 Pillow 和 numpy
- ffmpeg 和 ffprobe，要带 libx264 和 libass（烧录字幕）
- 中文字体：Windows 默认用微软雅黑，其他系统默认 “Noto Sans CJK SC”；也可以用 `--font` 或 `--font-file` 指定
- 下载和转写在你自己的电脑上做：`yt-dlp` 下载（只下载你有权剪辑的视频），`whisper` 转写成 JSON（英文访谈不要加 `--language zh`）

## 一页纸流程

1. **取素材**：视频加转写，用 `prep_transcript.py merge` 合并成整句。
2. **精剪主线**：3 个标题、一句话主张、开头 3 秒、3 到 5 个要点、结尾、出处表、原片占比。**这里停下，等你回复“开始”。**
3. **出预览**：写 plan.json（原片、讲解、图卡三种片段），只翻译用到的句子，540×960 低码率预览。讲解没录音时静音占位。
4. **技术审片**：T1 到 T8，脚本能判的自动判，人物标签、观感、数字出处对着联系表人工看。
5. **评审循环**：数据分析师和观众剪辑各按 12 项打分，两人都到 80 分、没有低于 3 分的项、没有必须修改的问题才通过，最多 4 轮。没有数据表时 D1 填 NA。
6. **出成片**：换上真实录音、补全翻译，再审一次。
7. **交接**：分数、改动、仍偏弱的项、发布前要人工确认的事。

## 每日素材采集

`tools/scout.py` 每天定时从 `scout/sources.json` 里的源（YouTube 频道、RSS、播客目录）拉新内容到收件箱，不花 Token；在 Claude Code 里输入 `/scout`，Claude 按“知名度、反直觉的话、具体数字”三条标准挑选，从字幕或原文里找出原话和时间码，写进选题池，等你选定后再下载。详见 `5-claude-code/本地运行指南.md` 第四节。

## v2 改了什么

| 问题 | 改动 |
|---|---|
| 只能拼原片，没有“自己的讲解” | plan.json 支持三种片段：原片、讲解（口播录音或静音占位）、图卡 |
| 字幕一段只有一行 | 按转写逐句出中文字幕，可加英文原文；新增 `prep_transcript.py` 做整句合并、待翻译清单、回填 |
| 平台是抖音加小红书 | 全部改成抖音加视频号；数据分析加“转发率”；封面工具加 9:16 |
| 竖屏画面利用率低，图卡和字幕可能打架 | 固定三区版式：上区标题和图卡，中区画面，下区字幕；T6 排版自动检查 |
| 没有来源标注 | 原片片段自动加来源角标和人名身份条 |
| “不整段搬运”无法检查 | 原片累计不超过一半、单段不超过 60 秒，超了警告（T8） |
| 网页版评审不独立 | 写明降级做法、交接里注明“评审不独立”，加了用旧视频校准评分的步骤 |
| 无数据时 D1 只能猜 | D1 可填 NA，不计入总分 |
| 提示词、skill、单文件版不一致 | skill 为准，单文件版由脚本生成，聊天提示词同步更新 |

## 已验证和没验证的

**已验证**（合成视频和合成数据，2026-11-13）：

- 三种片段都能渲染，预览和成片两档；中文图卡、高亮色、来源角标、身份条、逐句双语字幕显示正常
- 整句合并、待翻译清单、回填翻译
- 讲解段有录音和没录音两种情况；没录音时预览警告、成片判 fail
- T6 能查出图卡文字超行；T8 能查出原片占比超限
- D1 填 NA 时的总分计算；数据分析能读视频号常见列名、算出转发率
- 封面工具 3:4 和 9:16 两种尺寸

**没验证**：

- 没有用真实访谈和真实 whisper 输出跑过，整句合并的效果要在第一条真片上抽查
- 版式在抖音、视频号真实界面上的遮挡情况，需要发一条私密视频在手机上看
- 两个平台后台导出表的真实列名
- 评审提示词和 12 项评分没有用真实视频校准过
- 评分只说明剪得是否规范，不能保证播放量

## 边界

- 版权：只取必要片段，加上自己的讲解、翻译和判断，标明来源，必要时先联系版权方。不整段搬运。
- 画面里的每个数字、人名、引述都必须能在源视频里找到，找不到的删掉或标出来。
- 只复刻自己或已授权的声音；发布时按平台要求标注 AI 生成内容。

## 容易混淆的命名

`tech_qa.py` 是独立审片脚本；`tech_check.py` 的输出目录也叫 `tech_qa/`。前者是脚本文件，后者是输出文件夹。
